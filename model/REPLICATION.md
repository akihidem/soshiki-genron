# 複製深度(trials)の台帳 ── trials>1 が買うのは精度でなく**床の前提条件**

ロードマップの「trials>1 を全実証へ」を、標本の贅沢でなく**適用条件**として定式化する。生数値 [`replication_results.json`](replication_results.json)。

> [`noise.py`](noise.py) の検出床はセル反転率 f を要求し、f は独立2試行の不一致率 d=2f(1−f) からしか推定できない。**t=1 の実測は「床を超えていない」のでなく「床を計算できない」。** 一方 trials は検出力を買わない（[`gap.py`](gap.py) ①）── 検出力は n が買い、対応二値の符号検定では **n ≤ 5 でどんな観測も α=0.05 で有意にならない**。

## ① 台帳 ── 実測成果物の複製深度

`experiments/` の主張ファイル 52 件（`*_artifacts.json` は生ログなので除外）:

| 分類 | 件数 | 意味 |
|---|---|---|
| `REPLICATED`（trials≥2） | 17 | noise.py の床が**適用できる** |
| `SINGLE`（trials=1） | 2 | f が推定不能＝床が**立たない** |
| `UNDECLARED` | 33 | 成果物から深度を復元できない |

深度の宣言率 **37%**。`UNDECLARED` は「trials=1 だった」ではなく「**記録されていないので分からない**」である ── 台帳としては後者の方が重い。

## ② 再判定 ── 処方文書を支える trials=1 実測

`experiments/role_division_repair_real.json`（**trials=1・n=6**・タスク pytest-dev__pytest-11125, pytest-dev__pytest-11143, pytest-dev__pytest-11148, pytest-dev__pytest-11160, pytest-dev__pytest-11178, pytest-dev__pytest-11217）。`docs/deployment-architecture.md` は「役割を切らない」「やらない＝役割分業の固定パイプライン」をここから処方している。

per-task の二値ベクトル:

| 群 | ベクトル | 解決数 |
|---|---|---|
| `solo` | 0, 1, 1, 0, 1, 1 | 4/6 |
| `role_same` | 0, 1, 0, 0, 1, 1 | 3/6 |
| `role_cross` | 0, 1, 0, 0, 1, 1 | 3/6 |
| `test_loop` | 1, 1, 1, 1, 1, 1 | 6/6 |

厳密符号検定（両側・一致対は情報を持たないので落ちる）:

| 対比 | 平均差 | 不一致対 m | p | 判定 | 何の根拠か |
|---|---|---|---|---|---|
| 構造利得（役割分業 − solo） | -0.167 | 1 | 1 | **UNDECIDED** | 「役割を切らない」の根拠 −0.167 |
| 多様性利得（異モデル役割 − 同モデル役割） | +0.000 | 0 | 1 | **UNDECIDED** | cross の上乗せ |
| 総利得（役割分業 − solo） | -0.167 | 1 | 1 | **UNDECIDED** | 役割分業パイプラインの是非 |
| test 接地反復 − solo | +0.333 | 2 | 0.5 | **UNDECIDED** | 「L1 が既定ユニット」の根拠 |
| test 接地反復 − 役割分業 | +0.500 | 3 | 0.25 | **UNDECIDED** | 「+0.5 上回る」の根拠 |

**5 主張のうち有意は 0 件。** n=6 で到達可能な最小 p は 0.03125（全 6 対が一方向に不一致という最良観測）なので、n 自体は反証可能域に在る ── **観測がそこに届いていない**。「差が無い」ではなく「この標本は差の有無を決められない」である。

処方が偽だと言っているのではない。**処方を支える標本が、その処方を支えていない。**撤回された mesh の +0.042 と同型の失敗が、モデル層でなく**処方層**で起きている状態である。

## ③ n の値段 ── 符号検定が反証可能になる n

| n | 到達可能な最小 p | 反証可能か |
|---|---|---|
| 3 | 0.25 | **不可** |
| 4 | 0.125 | **不可** |
| 5 | 0.0625 | **不可** |
| 6 | 0.03125 | ✓ |
| 8 | 0.007812 | ✓ |
| 10 | 0.001953 | ✓ |
| 12 | 0.0004883 | ✓ |
| 24 | 1.2e-07 | ✓ |

**最小 n = 6。** これは観測に依らず実験を回す*前*に決まる。n=3 の群間比較（`role_division_real.json`）は trials=2 を持っていても、**どんな結果が出ても有意にならない**。複製深度と標本数は別々に返すしかない負債である。

## 含意 ── 「trials>1 を全実証へ」の正しい読み

- ✗ 「精度を上げるために試行を増やす」 → trials は構造的能力差の下で分散に**厳密にゼロ**しか寄与しない（gap.py ①）。
- ✓ **「全実証を noise.py の床の適用範囲に入れる」** ── t≥2 が一つでも在れば f が推定でき、撤回が*事後に*でなく*事前に*計算できるようになる。
- ✓ **検出力の負債は n で別に返す。** 群間比較では n≥6 が反証可能性の入口。
- ✓ **深度を記録しない実測は、負債かどうかすら判定できない。** `UNDECLARED` 33 件を減らすことが台帳の最初の一手。

## 反証条件

- 本ファイルが偽なら: (a) t=1 からセル反転率 f を推定する手続きが在る（d=2f(1−f) は独立2試行を要するので在り得ない）、または (b) 対応二値で n 対から 2^{1−n} より小さい両側 p を出せる厳密検定が在る（符号検定の帰無分布は Binomial(m,1/2) で m≤n、その最小両側裾は 2·2^{−n}）。
